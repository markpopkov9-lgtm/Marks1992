# Навыки Studio OS

Основные skills поставляются плагином `plugins/studio-os`:

- `studio-os-task` — рабочая задача от brief до QA;
- `studio-os-release` — очищенный Distribution Build;
- `studio-os-figma-handoff` — передача Figma ↔ Studio OS.

Skills задают рабочий процесс, но не предоставляют права, учётные записи или разрешение на публикацию. Новые skills добавляйте в плагин и включайте в `config/distribution.json` явно.
