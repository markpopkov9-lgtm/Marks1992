# Архитектура Studio OS
Пользователь / ChatGPT → Studio OS MASTER → JARVIS (цели, контекст, QA) → Codex → Git/GitHub → IDE + Node.js → Distribution Build.

Направления: Figma → дизайн; Claude или человек → независимое ревью; Tilda/web → публикация; Remotion/3D/AI → медиа; Marketing & Growth OS → гипотезы и результаты.

Это структура и контракты работы, не автономный сервер. GitHub, публикация, медиапайплайны и платные API подключаются отдельно. Передача задачи содержит цель, входы, разрешения, артефакты и критерии приёмки.
