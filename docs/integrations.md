# Integrations v1.0

## Активные

| Интеграция | Состояние | Назначение |
|---|---|---|
| Codex | Active | Основной исполнитель Studio OS и MARK Skills. |
| Git/GitHub | Active через HTTPS + Credential Manager | Репозиторий, история и переносимость. Отдельный `gh` CLI требует повторного входа только для команд `gh`; обычный Git работает. |
| Figma | Connected, manual | Design handoff по запросу; материалы клиента остаются в `local`. |
| Impeccable | Installed, project scope, no hooks | QA реализованного интерфейса. Runtime и рабочие данные исключены из Git. |

## По задаче

| Интеграция | Когда подключать |
|---|---|
| Claude Review | Когда нужен независимый второй review после основной реализации. |
| Tilda | Только для конкретной публикации или переноса сайта. |
| Remotion | Для видео, motion-креативов и программного рендера. |
| 3D/AI media | Для подтверждённой задачи с 3D или генеративными материалами. |
| Marketing & Growth | После появления продукта, сайта, оффера и измеримой цели. |

## Отложено

- HorizonX — до появления реальных long-horizon задач.
- GitHub CLI re-auth — не блокирует Git; выполнить перед использованием PR, Issues или других команд `gh`.

## Проверка

```powershell
node scripts/system-check.mjs
```

Health-check не обращается к внешним сервисам, не читает секреты и не выполняет платные операции.
