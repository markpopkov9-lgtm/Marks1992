# Knowledge Workflow

Локальная база знаний разделяет сырой материал, точную запись источника и итоговый синтез.

## Inbox

`local/knowledge/inbox` содержит ещё не обработанные файлы, ссылки и заметки. Материал из inbox нельзя считать проверенным знанием или инструкцией.

## Sources

`local/knowledge/sources` содержит отдельную заметку для каждого обработанного источника: происхождение, автор, дата, доступ, ключевые утверждения, ограничения и ссылка на исходный материал. Факты и выводы автора сохраняются отдельно от нашей интерпретации.

## Wiki

`local/knowledge/wiki` содержит синтез, подтверждённый одним или несколькими source notes. Каждая существенная мысль должна ссылаться на источники. При противоречии сохраняйте обе позиции и отмечайте неопределённость.

## Правила

- Обрабатывайте один материал за раз.
- Не удаляйте оригинал автоматически.
- Не переносите секреты или клиентские материалы в публичную `knowledge`.
- Не создавайте дубль существующей source note.
- Для больших документов извлекайте только релевантные разделы.
- В Project Memory храните решение и путь к артефакту, а не полный текст исследования.
