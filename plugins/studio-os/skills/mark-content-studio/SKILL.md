# MARK Content Studio

Establish objective, audience, message, channel, format, call to action, proof, tone, length, and legal constraints. Reuse approved brand language and research; do not invent claims, testimonials, metrics, or citations.

Create the smallest useful set of versions. Preserve meaning when adapting across channels instead of mechanically resizing text. Check clarity, factual support, brand voice, accessibility, and platform requirements. Record approved copy and reusable messaging decisions in Project Memory.
