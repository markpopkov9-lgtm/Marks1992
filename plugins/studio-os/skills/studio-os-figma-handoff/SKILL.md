# Studio OS Figma Handoff

Прочитайте `design/figma-handoff.md`. Используйте подключение Figma, выбранное пользователем, и проверьте аккаунт и доступ к конкретному файлу. Ссылку, file key, node id и приватные заметки храните в `local/design/`, а не в отслеживаемых файлах.

Перед реализацией получите структуру узла и визуальный эталон. Зафиксируйте цель, разрешённые действия, компоненты, состояния, адаптивность, шрифты и лицензии ресурсов по `templates/figma-handoff.md`.

Для чтения не изменяйте макет. Для записи используйте профильные Figma skills и выполняйте только изменения, входящие в задачу. Платный тариф, публикация библиотеки и изменения командных ресурсов не подразумеваются автоматически.

При design-to-code сравните реализацию с эталонным снимком в том же состоянии и размере. В результате укажите использованный файл и node id, сделанные изменения, проверку и ограничения доступности, которые нельзя подтвердить по макету.
