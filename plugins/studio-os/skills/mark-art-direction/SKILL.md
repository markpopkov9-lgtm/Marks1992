# MARK Art Direction

Use this layer after the UX/UI System has established the user flow and before work moves into Figma. Read the brief, brand rules, product constraints, and existing components. Preserve accepted UX decisions.

Choose one coherent direction and state its rationale. Define composition, hierarchy, typography character, color behavior, imagery, surface treatment, density, and motion posture. Prefer product-specific choices over fashionable defaults. Identify patterns to avoid because they conflict with the brand, audience, accessibility, or platform.

Do not generate implementation merely to demonstrate taste. Produce a compact direction brief with references, design decisions, constraints, and acceptance criteria. Record the approved direction in Project Memory and pass it to Figma handoff.
