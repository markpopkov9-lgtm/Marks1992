# Studio OS Release

Источник сборки — MASTER. Состав Distribution задаёт `config/distribution.json`; не копируйте весь репозиторий и не включайте `.git`, `local`, секреты или клиентские материалы.

Перед сборкой проверьте состояние Git и просмотрите новые файлы. Затем выполните:

```sh
node scripts/release.mjs
```

Команда должна пройти проверку состава и тесты, создать новую версию в `../Distribution-Build/` и записать SHA-256 manifest. Не удаляйте предыдущие сборки автоматически.

После сборки назовите созданный каталог и результаты проверок. Напомните о ручном просмотре перед внешней передачей. Публикация в GitHub Releases, облако или другой сервис требует отдельного запроса пользователя.
