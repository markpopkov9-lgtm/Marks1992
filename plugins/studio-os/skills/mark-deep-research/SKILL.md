# MARK Deep Research

Define the decision, evidence threshold, time boundary, and exclusions. Reuse verified research recorded in Project Memory when it remains current. Search current primary sources first; use secondary sources for discovery or independent context.

For large documents, locate relevant sections and extract bounded passages rather than loading the whole file. Track source, publication or update date, access date, claim supported, and uncertainty. Separate facts, source statements, and inference. Finish with decision-relevant findings, unresolved gaps, and source links.
