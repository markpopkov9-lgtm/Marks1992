# MARK Impeccable QA

Use this after implementation and before delivery. Confirm that the official project-scoped Impeccable skill is installed. Do not download, update, enable hooks, or execute a remote binary automatically.

Run a focused audit on the implemented surface. Treat deterministic findings separately from visual judgment. Reconcile recommendations with the existing UX/UI System, brand direction, accessibility requirements, and project scope. Do not let an external rule silently replace an accepted product decision.

Prioritize verified issues by user impact and fix only within the authorized scope. Re-run the focused audit after fixes. Store the result and unresolved exceptions in Project Memory. If Impeccable is unavailable, report that state and use the existing Studio OS QA checklist without pretending its detector ran.
