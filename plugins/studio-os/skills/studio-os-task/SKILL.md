# Studio OS Task

Работайте из корня MASTER. Сначала прочитайте корневые `AGENTS.md`, `README.md` и подходящий файл из `workflows/`.

Для новой работы создайте или обновите приватное задание в `local/tasks/` по `templates/task.md`. Зафиксируйте цель, источники, разрешённые изменения, ожидаемые результаты и критерии приёмки. Не добавляйте заполненные приватные задания в Git.

Перед изменениями проверьте состояние Git и сохраните чужие незавершённые изменения. Выполните задачу в минимальном необходимом объёме. Не публикуйте, не отправляйте сообщения и не запускайте платные операции без явной авторизации.

Проверьте результат по `workflows/qa.md`. Для изменений ядра запустите:

```sh
node scripts/jarvis.mjs check
node --test tests/distribution.test.mjs
```

В итоговом сообщении укажите результат, проверки, ограничения и следующий практический шаг.
