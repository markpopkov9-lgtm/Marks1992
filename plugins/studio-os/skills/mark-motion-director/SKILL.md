# MARK Motion Director

Decide first whether motion improves orientation, feedback, continuity, explanation, or delight. Remove it when the interaction is frequent, keyboard-driven, distracting, or slower than the state change.

Reuse existing motion tokens and the cheapest suitable technology. Prefer interruptible transitions for repeated interactions and transform/opacity for smooth rendering. Define trigger, start and end state, origin, duration, easing, interruption behavior, exit behavior, and reduced-motion alternative. Gate hover-only effects to devices that support hover.

Review motion in context and at reduced speed. Flag unjustified animation, sluggish response, incorrect transform origin, layout-property animation, inaccessible movement, inconsistent timing, and motion that conflicts with the product character. Pass implementation findings to Impeccable QA when it is installed.
