# Figma → Studio OS
1. Получить ссылку на конкретный файл и фрейм (node-id).
2. Проверить чтение метаданных или скриншота. Доступ к аккаунту не гарантирует доступ к файлу.
3. Для реализации получить контекст дизайна и визуальный эталон инструментами Figma.
4. Зафиксировать компоненты, размеры, шрифты, цвета, состояния и адаптивность.
5. Личные ссылки и экспорты сохранить в local/design по templates/figma-handoff.md.
6. Реализацию проверить сравнением с макетом и передать на ревью.
7. Изменять макет только в пределах задачи и доступных прав.

Используем уже доступное соединение Figma в Codex. Отдельный API token для этого процесса не нужен. При недостаточных правах можно начать с разрешённого экспорта PNG/SVG/PDF. Платный тариф автоматически не включается.
